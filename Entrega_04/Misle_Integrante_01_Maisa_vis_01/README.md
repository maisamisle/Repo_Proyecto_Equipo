## Tema de la crónica

La crónica aborda cómo los ataques a hospitales en Gaza han dificultado el acceso a la atención médica, especialmente para mujeres embarazadas y recién nacidos. Se analizaron 795 incidentes entre 2023 y 2025.

## Proceso de creación del sitio web

Se organizaron los datos y se crearon gráficos interactivos con Python y Altair. Para el sitio se utilizó **HTML**, con etiquetas como `<h1>`, `<h2>`, `<p>` e `<img>`, para incorporar títulos, textos e imágenes. En **CSS** se usaron propiedades sencillas como `color`, `background-color`, `font-size`, `margin` y `padding` para definir los colores, tamaños de letra y espacios de la página.
