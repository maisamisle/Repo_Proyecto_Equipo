# Tema de la crónica
La crónica escrita refiere al avance en mortalidad infantil de un grupo específico de niños (0-1 años) durante el transcurso de la guerra en Gaza. Los periodos descritos corresponden a aquellos que producen fluctuaciones clave en la base de datos realizados y se le asigna una mirada humanitaria desde la observación a las víctimas más vulnerables del conflicto.

# Proceso de creación del sitio web
Se organizaron los datos en función del grupo de interés específico y se construyó una serie de gráficas perfeccionadas sistemáticamente a través de Altair. La crónica fue redactada y asignada a un sitio web. Armé la página en HTML con las etiquetas vistas en clases: `<h1>` para el título, `<h2>` para el subtítulo, `<p>` para los párrafos de la crónica, `<img>` para insertar la imagen del gráfico y `<a>` para el enlace a la fuente de los datos. Tuve algo de complicaciones con respecto al diseño de la página.
